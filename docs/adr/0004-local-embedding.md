# ADR-0004: 本地确定性 Embedding，生产通过 EmbeddingPort 替换多模态模型

- 状态：已接受（2026-11-11）
- 关联：AC-12、PRD §3.2

## 背景
离线环境无法调用云端多模态 Embedding；需要可复现、可测试的文字与图片查询链路。

## 决定
1. `EmbeddingPort` 定义 `embedText` 与 `embedImage`，维度 256。
2. 本地实现使用 FNV-1a 哈希字符 n-gram + 词元，L2 归一化；图片把字节直方图与
   caption/文件名文本混合到同一空间。
3. 检索排序在向量余弦之外混入词法覆盖率，避免中文长文档稀释相似度。
4. 生产替换点：CLIP 类双塔模型或视觉描述 + 文本模型，只需实现 `EmbeddingPort`。

## 后果
- 完全离线、确定性、无外部密钥；语义泛化弱于真实模型。
- UI 与 ADR 均明确标注 `local-hash-256`，避免把演示实现误认为生产模型。
