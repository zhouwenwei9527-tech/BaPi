# ADR-0009: 本人资料自助、审批风险与个性化

- 状态：已接受（2026-11-12）
- 关联：PRD §7、AC-03、AC-07

## 决定
1. 本人修改姓名/职位通过 `PATCH /api/users/me/profile` 直接生效并写审计；不生成审批。
   修改他人资料、调整角色、删除用户仍走 `user.update` / `user.assignRole` / `user.delete` 审批。
2. `ToolExecutor.describe()` 提供审批展示：一句话意图、0-100 可操作度、风险原因、是否需二次确认。
   Gateway 创建审批时持久化这些字段；`operability < 60` 时后端强制 `confirmRisk=true`。
3. 审批 UI 展示意图与风险条；批量审批返回逐条结果并统计成功/失败；自批条目不可选择。
4. 壁纸与程序坞/桌面布局属于浏览器本地偏好，存 `localStorage`，不经过 Gateway、不需要审批；
   Agent 图片换壁纸由前端直接应用。
5. 用户状态、副作用、审批/插件/申请状态等用户可见枚举统一由 `src/lib/labels.ts` 映射为中文。

## 后果
- 低风险的个人资料修改不再制造无意义审批；高风险角色/删除操作有明确风险提示与二次确认。
- 个性化偏好不跨设备；风险评分为规则基线，后续可替换为策略引擎。
